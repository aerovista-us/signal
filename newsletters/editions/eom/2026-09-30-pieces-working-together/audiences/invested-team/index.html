Incidents that changed the rules

Keep the lesson, not just the fix.

The point is not to hide failure. It is to make sure the same class of failure becomes harder to repeat.

AV-MEMORY

Unbounded relationship build

A legacy graph operation accumulated tens of millions of retained relationships and caused severe memory pressure. The accepted graph survived. The September decision was clear: corpus-wide work must be bounded and fail closed.

RydeSync runtime

Tracked code was not the whole runtime

A stash operation removed untracked routing files and temporarily broke Account routing. Runtime-critical definitions must be tracked and restorable.

Public web

Production stayed ahead of source provenance

The known-good public site remained live when current source could not reproduce the production Auth/AVCC behavior. Platform work was isolated instead of forcing a risky deploy.

Governance

Work Log lineage remains unresolved.

Canonical revision 10+ was not recovered. Reconstruction can support reconciliation, but it must not masquerade as the missing authority.

Team operating principle

Build less from zero.

When a new project needs identity, commerce, publishing, permissions, operational reporting, or evidence handling, first ask whether a governed AeroVista capability already exists. Reuse is now part of the product strategy—not merely code cleanup.
