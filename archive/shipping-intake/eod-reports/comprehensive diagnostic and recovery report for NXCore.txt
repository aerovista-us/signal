🧩 Key Errors & Root Causes
1. rsyslog write errors / “message lost”
action-3-builtin:omfile write error — see https://www.rsyslog.com/solving-rsyslog-write-errors


Cause: /var/log (or /) nearly full → write failures → rsyslogd back-pressure → CPU spike.

Impact: system logs not written, service health degraded.

Fix:

sudo journalctl --vacuum-time=3d
sudo du -sh /var/log/*
sudo truncate -s 0 /var/log/syslog /var/log/kern.log /var/log/auth.log
sudo systemctl restart rsyslog

2. libvirtd “failed to create mdevctl thread”
failed to create mdevctl thread: Resource temporarily unavailable


Cause: high CPU load or thread limit (ulimit) hit during libvirt startup.
Fix: increase process limits and restart libvirtd:

sudo systemctl restart libvirtd
sudo prlimit --pid $(pidof libvirtd) --nofile=65536:65536

3. Missing UDisks2 modules
Error initializing module 'lvm2' / 'iscsi' / 'btrfs': cannot open shared object file


Cause: partial package install or cockpit-storage plugin mismatch after 24.04 update.
Fix:

sudo apt install --reinstall udisks2 libblockdev-lvm2 libblockdev-btrfs libblockdev-iscsi
sudo systemctl restart udisks2

4. Cockpit web console 404 / MIME errors
po.manifest.js / po.js 404; MIME type text/html not executable


Cause: missing localized resource bundles under /usr/share/cockpit/@localhost.
Fix:

sudo apt reinstall cockpit cockpit-bridge cockpit-system
sudo systemctl restart cockpit.socket


Optional: clean browser cache or force-refresh (Ctrl + F5) after repair.
